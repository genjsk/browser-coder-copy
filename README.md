# 网页代码复制助手

Chrome / Edge 扩展，用于读取和复制头歌、其他在线 IDE、编程题网站及技术文档中的代码。扩展按页面结构识别 CodeMirror 5/6、Monaco、Ace、普通文本框、可编辑区域及 `<pre>` 代码块，也可以读取手动选中的网页文字。

## 安装或更新

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 打开开发者模式，点击 **加载已解压的扩展程序**，选择 `educoder-copy-helper` 文件夹。
3. 已安装旧版时，在扩展管理页点 **重新加载**，再刷新目标网页。

## 使用

1. 打开目标网页，点击扩展图标。弹窗会自动寻找代码区，也可以手动点击 **读取代码**。
2. 页面有多个代码区时，可用 **代码来源** 下拉框指定。也可以先点一下网页里的代码区，再选择 **当前光标所在编辑器**。扩展会按站点记住选择。
3. 网页文字或没有识别到的代码可以手动框选，再点 **读取选中文字**。
4. 点击 **复制到剪贴板**，或选中预览里的代码按 `Ctrl+C`。

扩展会把不换行空格等特殊空白转换为普通空格，保留中文。头歌（`educoder.net` 及其子域）仍沿用原先的字面 `NBSP` 修复，其他站点可正常复制名为 `NBSP` 的变量或字符串。

保留 **页面解锁** 开关为开启时，可以在页面上选中文本后直接复制。切换开关后刷新页面。

### 强制读取

如果编辑器只把可见行渲染到页面，先在网页里点一下代码正文，再点 **强制读取（Ctrl+A/C）**。首次使用需在弹窗中启用调试权限。此操作通过浏览器发送全选和复制快捷键，并将剪贴板中的代码显示在预览里。

预览提示只有可见行时，点击 **复制到剪贴板** 会先尝试从选中的编辑器读取完整代码。如果仍无法确认是否读全，弹窗会提示预览可能缺行。

画布编辑器须有可用的页面复制功能才能读出文字。纯图片里的文字不在读取范围内。

### 排查读取失败

- 读到了测试用例框时，在 **代码来源** 下拉框选代码区。
- 提示只读到可见部分时，用 **强制读取（Ctrl+A/C）** 尝试读取全文。
- 提示调试器被占用时，关闭该标签页的开发者工具再试。
- 扩展识别不到代码区时，点击 **检查当前页** 和 **复制诊断**，可查看候选编辑器及所在框架。

## 权限

| 权限 | 用途 |
| --- | --- |
| `activeTab`、`scripting`、网页访问 | 识别并读取页面及子框架里的编辑器 |
| `clipboardWrite` | 将代码和诊断信息复制到剪贴板 |
| `clipboardRead` | 将强制读取得到的代码显示在弹窗中 |
| `debugger` | 强制读取时发送全选与复制快捷键，以及读取编辑器时的备用通道 |
| `storage` | 保存编辑器选择、页面解锁开关和调试授权 |

## 本地测试

`test/e2e.mjs` 用无头 Chrome 加载扩展，覆盖普通文本框、CodeMirror、Monaco、iframe、影子 DOM 及画布的读取和复制场景。

```powershell
node test/e2e.mjs
```

可用 `CHROME_PATH` 指定浏览器路径，用 `E2E_HTTP_PORT` 和 `E2E_DEBUG_PORT` 指定测试端口。
